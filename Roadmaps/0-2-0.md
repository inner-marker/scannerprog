# Roadmap 0.2.0 – Scanner Control Page

Status: the page UI is superseded by `0-2-1 SCANNER_PAGE_PLAN.md` (Phase 1 built). Earlier status: phases 1-4 implemented (1-2 verified on hardware; 3-4 untested). Phase 5 not started.
Target model: Uniden BCD325P2 (other models gated by capability flags).

## What the scanner exposes (BCD325P2 remote commands)

Reference: `docs/Model Specs/BCD325P2_Remote_Command_Reference.md`

### Viewing (read-only)

- **Live status:** `GLG` (frequency, mode, system/group/channel names, squelch, mute, weather alert), `STS` (display contents), `PWR` (RSSI), `GID` (current talkgroup ID).
- **Current settings:** `VOL`, `SQL`, `BLT`, `KBP`, `PRI`, `AGV`, `SCO`, `CLC`, `WXS`, `P25`, `MDL`, `VER`.
- **Database:** already downloaded by the app (systems, groups, channels); the control page can read from the in-memory/RON copy. Live reads: `SIH`/`SIN`, `GIN`, `CIN`.
- **Quick keys:** `QSL` (system quick-key lockout, 100 keys, 10 per page), `QGL` (group quick keys within a system). Values are 0/1/2 (confirm meaning of `2` in the spec before use).

### Controlling

- `JPM` jump mode: `SCN_MODE` (channel), `SVC_MODE` (service search), `CTM_MODE` (custom search), `CC_MODE` (Close Call), `WX_MODE` (weather), `FTO_MODE` (tone-out).
- `JNT` jump by number tag; `QSH` hold on a frequency (VFO).
- `QSL` / `QGL` set quick-key lockouts (the way to scan only specific systems/groups).
- `LOF` / `ULF` lock out / unlock a frequency; `GLF` lists global lockouts.
- `KEY` emulates any button press (Scan, Hold, L/O, Menu, digits, F+key).
- `VOL` / `SQL` volume and squelch; `MNU` menus; `POF` power off.

Constraints:

- Program-mode commands (`PRG`/`EPG`) halt scanning. Changing quick keys/settings means enter program mode, write, exit. Exit lands in Scan Hold, so a scan `KEY` is probably needed to resume.
- Status polling (`GLG`) must not run concurrently with download/upload; one shared serial connection with a lock/queue.
- One command in flight at a time.

## Built-in (hard-coded) searches

These are not database systems; list them in the UI as "Searches", separate from user systems.

- **Service search** (`SVC_MODE` / `SSP`), 12 banks: Public Safety, News, HAM, Marine, Railroad, Air, CB, FRS/GMRS/MURS, Racing, FM Broadcast, Special, Military Air. Per-bank settings (delay, attenuation, hold, lockout, quick key) via `SSP`.
- **Weather** (`WX_MODE`): `NORMAL`, `A_ONLY`, `SAME_1`..`SAME_5`, `ALL_FIPS`. Configure with `WXS` / `SGP`.
- **Close Call** (`CLC` / `SCO`, band filter via `MNU,CCBAND_MENU`).
- **Custom search**: 10 user-defined ranges (`CSG` / `CSP`).
- **Location alerts** (spec section 7.9).

## Decisions

1. **"Scan only X" is temporary.**
   - Snapshot `QSL` pages and the relevant `QGL` data before changing quick keys.
   - Show a banner: "Temporary scan filter active – Restore"; Restore writes the snapshot back.
   - Auto-restore when remote control is turned off or the app closes.
   - Persist the snapshot to disk so a crash/unplug does not leave the scanner with wrong keys; on next connect, offer to restore.
2. **BCD325P2 only for now.**
   - Add a `ControlCapabilities` struct on the model trait in `src/models` (e.g. `live_status`, `quick_keys`, `service_search`, `weather`).
   - Unsupported models report `false`; the control page shows "not supported for this model".
3. **Control only on the control page, with a Remote Control toggle.**
   - Toggle defaults to off. Controls are always rendered but disabled while off.
   - Turning on: open the serial connection, take a one-time settings snapshot, start `GLG` polling.
   - Turning off: stop polling, restore any temporary filter, release the port (frees it for Database upload/download).
   - Database page upload/download buttons are disabled while remote control is on, with a hint to turn it off first.
   - Leaving the control page turns remote control off.
4. **Weather uses the scanner's own modes.**
   - Send `WX_MODE` via `JPM` (`NORMAL`, `A_ONLY`, `SAME_1`..`SAME_5`, `ALL_FIPS`).
   - Display-only static UI table of NOAA frequencies: WX1 162.400, WX2 162.425, WX3 162.450, WX4 162.475, WX5 162.500, WX6 162.525, WX7 162.550 MHz.
   - In weather mode, show the live frequency from `GLG` with its WX channel label.

## Page layout (new `Route::ControlPage`, "Scanner" nav link)

1. **Remote Control toggle** at the top.
2. **Now Playing panel:** polls `GLG` at ~2–4 Hz while visible; frequency, system, group, channel, signal meter, mode.
3. **Transport buttons:** Scan, Hold, Skip/Lockout, Prev/Next, plus volume and squelch sliders (`KEY`, `VOL`, `SQL`).
4. **Quick key grid:** 100 system quick keys plus group quick keys for the selected system; labelled with names from the database; on/off state; toggles via `QSL`/`QGL`.
5. **Systems/Groups tree:** from the downloaded DB. "Jump to" via `JPM`/`JNT`; "Scan only this" disables all others via `QSL` (temporary, see Decisions).
6. **Searches tab:** 12 service banks, weather mode picker with frequency table, Close Call, Custom search; settings editors via `SSP`, `WXS`, `CLC`.
7. **Settings summary:** read-only display of backlight, priority, key beep, etc.

## Implementation approach

- **Serial layer:** replace per-operation port opening in `scanner_interaction` with a long-lived connection owner (background thread/task with a command channel). Add typed `ScannerModel` extension methods (`status()`, `jump()`, `set_quick_keys()`, ...) so BC346XT/BCD396XT can be added later (their command sets differ; capabilities are per-model).
- **State:** global `Signal<LiveStatus>` fed by the poller. Pause polling during download/upload and Database edits.

## Phases

1. **Foundation** (done)
   - `Route::ControlPage` and nav link.
   - Connection actor (thread owns the port; commands over a channel), capability flags, `RemoteControl` global signal.
   - Toggle UI with disabled-state styling; Now Playing panel from `GLG`.
2. **Basic control** (done; `KEY` codes checked against the spec, Prev/Next use VFO `<`/`>`, which needs hardware verification)
   - Volume/squelch sliders; `KEY` buttons (Scan, Hold, Skip/L-O, Next, Prev). Verify key names against the `KEY` table in the spec first.
3. **Searches** (done)
   - Service search buttons (12 banks), weather mode picker with frequency table, Close Call, Custom search via `JPM`.
4. **Quick keys and scan filter** (done)
   - System and group quick-key grids named from the database; toggle with `QSL`/`QGL`; "scan only this" with snapshot/restore.
5. **Settings editing**
   - `SSP`, `WXS`, `CLC` editors; read-only settings summary.

## Risks to verify on hardware first

- Whether `QSL`/`QGL` can be written without `PRG` (the spec lists them as program-mode). If not: enter program mode, write, exit, resume scanning, with a brief scan interruption.
- Which command resumes scanning after `EPG` (scanner lands in Scan Hold); likely a scan `KEY`.
- Meaning of quick-key value `2` in `QSL`/`QGL`.
